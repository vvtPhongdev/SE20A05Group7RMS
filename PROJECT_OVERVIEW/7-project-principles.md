# 7. Project Principles

1. **Explainability > Ranking Accuracy** — Structured evidence beats opaque scores
2. **Deterministic Scoring** — Readiness comes from vectors, graphs, and rules — no LLM
3. **Provenance Is Core** — Every claim traces to source evidence
4. **Human Override Is First-Class** — Reject, comment, correct — corrections become organizational knowledge
5. **Marketplace Flow, Not Dashboard** — Discovery feeds and flows, never static data tables
6. **Two-Way Transparency** — Both sides see what AI understands and can challenge it
7. **Evidence-First UX** — Every AI claim is one click from its source
